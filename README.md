# Keno Web Game

A fun, interactive, and visually engaging web-based Keno game. Experience the excitement of Keno with smooth animations, multiple themes, and real-time statistics.

## 🎮 Features

- **Interactive Gameplay**: A 10x8 grid of numbers where you can select your lucky numbers.
- **Dynamic Themes**: Customize your experience with various visual themes:
  - 🚀 **Space**
  - 🌊 **Ocean**
  - 🏜️ **Desert**
  - 🌲 **Forest**
- **Suspenseful Draws**: Watch numbers being drawn sequentially for a realistic game feel.
- **Smart Selection**:
  - Manually select 2 to 10 numbers.
  - Use the **Random Pick** button to let the computer choose for you.
- **Real-time Stats**: Keep track of your:
  - Total Credits
  - Games Played
  - Total Winnings
- **Responsive Design**: Playable on various screen sizes with a modern, polished UI.

## 🕹️ How to Play

1. **Select Your Numbers**: Click on the numbers in the grid to select them. You can choose between **2 and 10 numbers**.
2. **Start the Game**: Once you've selected your numbers, click the **Start Game** button.
3. **Watch the Draw**: The game will sequentially draw numbers.
4. **Win Credits**: If the drawn numbers match your selected numbers, you win credits based on the prize table!
5. **Reset or Randomize**: 
   - Use **Reset Game** to clear your selections and start over.
   - Use **Random Pick** to quickly fill your selection with random numbers.

## 🛠️ Tech Stack

- **HTML5**: For the structure of the game.
- **CSS3**: For advanced styling, animations, and theme transitions.
- **Vanilla JavaScript**: For the game logic, state management, and interactive elements.

## 🚀 Getting Started

No installation required! To play the game:

1. Download or clone this repository.
2. Open `keno.html` in any modern web browser (Chrome, Firefox, Edge, or Safari).
3. Enjoy!
